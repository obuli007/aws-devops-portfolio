## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/obuli007/aws-devops-portfolio.git
```

2. Navigate to the project folder:

```bash
cd aws-devops-portfolio
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

5. Open your browser:

```text
http://localhost:8050
```

## Run Using Docker

Build the Docker image:

```bash
docker build -t aws-devops-portfolio .
```

Run the container:

```bash
docker run -d --name aws-devops-portfolio-container -p 8055:8050 aws-devops-portfolio
```

Open:

```text
http://localhost:8055
```
